Comment le projet sera construit

Tu n'as pas besoin de comprendre cette page pour utiliser l'outil. Elle explique les choix pour que n'importe quel développeur ou agent IA (Claude, Gemini, Antigravity…) puisse reprendre le projet.

Le principe anti-régression : chaque modèle est dessiné à des instants précis (0,3 s, 1 s, fin…) et comparé à une image de référence. Si une animation change sans qu'on l'ait voulu, le contrôle échoue et rien n'est publié.

Règles pour les agents IA

  • AGENTS.md est la source unique : commandes, architecture, conventions. Lu par Claude, Gemini/Antigravity, Codex, Cursor.
  • CLAUDE.md et GEMINI.md y renvoient et ajoutent tes préférences personnelles.
  • Ajouter un modèle = ajouter un dossier dans templates/, sans toucher au reste.
  • Une fonctionnalité = une branche + une pull request vérifiée.

Ce dont j'aurai besoin de toi

  • Un compte GitHub et l'outil gh connecté (je te guiderai, une commande à taper).
  • Le logiciel de montage de l'équipe, pour choisir le bon format d'export.
  • Le kit de marque : logo (PNG/SVG transparent), couleurs, polices.
  • 1 ou 2 vidéos d'exemple déjà montées, pour caler le style.

Aide

Dans la vraie version, ce panneau contient un guide pas à pas et une visite guidée au premier lancement.

Comment mettre le titre sur ma vidéo ?

Exporte, puis glisse le fichier sur une piste au-dessus de ta vidéo dans ton logiciel de montage. Le fond transparent laisse voir ta vidéo dessous.

Mon logiciel affiche un fond noir

Ton logiciel ne lit pas ce format transparent. Reviens à l'étape Exporter et choisis ton logiciel dans la liste : DStudio choisit le bon format.

Je veux faire 10 synthés d'un coup

Choisis le modèle « Synthés en lot » et colle ta liste : tu récupères un fichier par personne.
